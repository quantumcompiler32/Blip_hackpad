# Split device and host responsibilities

Blip uses a hybrid architecture: firmware on the XIAO continuously scans inputs, drives displays, stores hardware configuration, and provides Offline Controls, while the always-running Blip Agent executes profile-dependent macOS and integration actions. The right encoder provides volume and play/pause offline, while both left-encoder inputs are profile-dependent Agent commands. SW11 cycles device-owned profile state offline before synchronizing it on reconnection, and SW12 reports `AGENT OFFLINE` when its host command is unavailable. Control Center edits configuration rather than regenerating firmware; reflashing is reserved for embedded firmware changes. This keeps essential hardware behavior available without the host while allowing rich actions that the XIAO cannot perform independently.
