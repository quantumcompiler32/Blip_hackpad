# Use consent-based onboarding

First launch explains and explicitly requests enabling the bundled Blip Agent login item, whose enabled and running state remains visible and reversible; if disabled, Control Center may run it only for the current session. Onboarding offers physical-device or simulator setup and requests notifications, Accessibility, Automation, Screen Recording, weather city, notes folder, and Codex detection only when their dependent features are enabled. Blip uses no hidden persistence mechanism.
