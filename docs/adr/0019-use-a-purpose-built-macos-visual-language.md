# Use a purpose-built macOS visual language

Control Center presents as a polished macOS utility with sidebar navigation, compact status chrome, a hardware-centered dashboard, live display previews, direct key-map Test/Edit modes, system light/dark appearance, restrained depth, strong typography, contextual forms, reduced-motion support, and secondary advanced diagnostics. Its hardware-instrument visual identity uses graphite and warm off-white foundations, fine-line and grid details, amber for Main, electric blue for Coding, and teal for Research; semantic status colors are not decorative. System typography is used except for commands, logs, branches, and protocol data, while icons come from one coherent line style. Motion communicates connection, selection, progress, and completion. Its design system deliberately avoids generic AI-generated aesthetics: gratuitous gradients and glow, excessive cards and pills, arbitrary purple accents, oversized marketing headings, emoji-as-interface, repetitive helper copy, fake metrics, empty charts, inconsistent spacing, generic productivity slogans, and decoration without information value. A throwaway interactive prototype is visually reviewed against real Blip workflows before production implementation; design decisions are retained and prototype code is discarded.
