# Assign distinct display roles

The 0.96-inch 128×64 graphical OLED is the small display and presents Persistent Status, while the Newhaven 20×4 character OLED is the large display and presents Contextual Status. The Blip Agent owns the content model and firmware renders it through display-specific adapters, using graphical animation on the pixel display and character-appropriate transitions and custom glyphs on the 20×4 display. Ambient Status may rotate through time/date, weather, the next Pomodoro transition, active app or project, connection health, and decorative animation only when higher-priority status leaves room. Weather defaults to a manually configured location, is cached and marked stale offline, and macOS location access is optional. Animation has reduced-motion and timing controls. The first release provides built-in ambient cards rather than a general widget API. Both displays share the 3.3 V I²C bus without a mux: the graphical OLED uses `0x3C`, while the Newhaven uses `0x3D` with `SA0` tied high. For the Newhaven, `VDD` and `/RES` are held at 3.3 V, `REGVDD` is grounded, and the interface-selection pins remain configured for I²C. Combined bus pull-up strength must be verified before manufacturing.
