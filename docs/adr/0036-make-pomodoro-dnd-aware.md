# Make Pomodoro DND-aware

The DND setup assistant guides the user to allow Blip notifications through the selected macOS Focus mode and requests Time Sensitive notification capability where supported. Control Center tests notification and alarm behavior while that Focus is active and warns when macOS still suppresses it; the physical displays always report timer completion. Blip never bypasses system Focus controls without permission, and Focus Mode may optionally invoke its configured Shortcut to disable DND when the work session ends.
