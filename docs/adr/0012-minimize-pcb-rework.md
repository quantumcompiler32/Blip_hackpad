# Minimize PCB rework

Hardware revision one preserves the existing schematic placement, routed board, matrix topology, and component layout unless validation finds a concrete safety, electrical, manufacturability, or controller-compatibility defect. Corrections should be the smallest evidence-backed edits that pass the Hardware Validation Gate; aesthetic rerouting and speculative redesign are out of scope. The existing diode direction and row/column scan arrangement remain unchanged if schematic inspection, firmware agreement, and continuity checks validate them.
