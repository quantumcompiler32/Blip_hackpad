# Persist Pomodoro across runtime interruptions

The Blip Agent owns Pomodoro state and persists the active phase, remaining duration, and target end time in SQLite. Control Center closure and device disconnection do not affect the timer; Mac sleep counts as elapsed time, and wake or Agent restart reconstructs the correct state without silently advancing through multiple automatic cycles. Pause freezes remaining time, reset restores the configured work duration, displays resynchronize on reconnection, and completed-session logging remains optional. Each phase transition produces a macOS notification and a configurable one-shot alarm enabled by default, with Start Break/Work, Add 5 Minutes, and Dismiss actions. While an alarm is active, right-encoder press dismisses it; otherwise that control remains play/pause. Control Center includes Test Alarm and clear notification-permission guidance, and the displays show the completed phase and next action.
