# Integrate through stable Codex CLI execution

Blip integrates with the installed Codex CLI through stable non-interactive `codex exec --json`, parsing its JSONL event stream and reusing CLI-managed authentication without reading or exporting credentials. Plan and review actions run read-only; explicitly requested implementation, fix, and test actions use workspace-write restricted to the selected project, and Blip never offers danger-full-access. Runs are explicit and cancellable, while prompts, working directory, CLI version, redacted events, diffs, and results enter the audit log. Git publication remains a separate approved Feature Forge responsibility, missing or signed-out CLI states receive exact setup guidance, and Research still produces useful structured captures without an AI provider.
