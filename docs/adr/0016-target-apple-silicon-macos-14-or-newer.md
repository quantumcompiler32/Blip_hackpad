# Target Apple Silicon macOS 14 or newer

The Foundation Release targets Apple Silicon Macs running macOS 14 Sonoma or newer and is primarily tested on Moksh’s arm64 Mac running macOS 26.4.1 (build 25E253). An unsigned local development build comes before signing, notarization, and distributable packaging; Intel support is deferred until demonstrated need exists. Accessibility, Automation, Screen Recording, and notification permissions are requested per feature, with clear guidance and independent degradation when denied.
